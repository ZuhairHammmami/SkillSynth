# SkillSynth Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the student (`src/frontend`) and admin (`src/admin-app`) front-ends as SvelteKit + hand-written-CSS "Warm Craft" applications, fully replacing the React/Next/Tailwind/shadcn stack while preserving every backend-API-backed behavior.

**Architecture:** Two separate SvelteKit projects rebuilt in place (same folder names) so `skillsynth run` continues to launch them. Shared pattern per app: a `$lib/api` fetch client + a tiny `$lib/query` cache store (preserving Svelte-invalidation key strings), Svelte stores for auth/locale/sse, hand-rolled i18n (student), custom inline-SVG icons, and a hand-written CSS design system driven by CSS custom properties. No UI-kit libraries.

**Tech Stack:** SvelteKit, Svelte 5 (runes), Vite, TypeScript, `@sveltejs/adapter-auto`. Hand-written CSS (logical properties for RTL). Native `fetch`. No Tailwind/Radix/shadcn/TanStack/axios/lucide/sonner.

**Spec:** `docs/superpowers/specs/2026-08-26-redesign-design.md`

## Global Constraints

- Backend FastAPI + `skillsynth run`/seed/test stay **unchanged**; rebuild only inside `src/frontend` and `src/admin-app`.
- API base URL: `PUBLIC_API_BASE_URL` env (default `http://127.0.0.1:8000/api`). Student cookie `authToken`; admin cookie `adminToken`.
- Preserve exact SSE invalidation query-key strings (student `compat` keys: `['profile']`, `['dashboard']`, `['path']`, `['path', id]`, `['analyticsDashboard']`, `['skillGrowth']`, `['wizardOptions']`, `['learningAnalysis']`; admin keys listed in Task 30).
- Bilingual AR/EN parity (595-key catalogs ported verbatim) + RTL via CSS logical properties; never use physical `left/right`.
- Visual identity: paper `#FBF6EC`, ink `#2A2521`, muted `#8A7B6C`, accent ochre `#B5862E`, secondary sage `#7C8A6B`. Fonts: Bricolage Grotesque (Latin display), El Messiri (Arabic display), Public Sans (body). No blue/white/gray SaaS look.
- Every function/file carries a docstring/comment stating its single purpose (per AGENTS.md).
- No file > 300 lines (data/seed-style modules excepted); no function > 40 lines.
- Keep `package.json` `dev`/`build`/`preview`/`check` scripts; `skillsynth run` spawns `pnpm dev`.

## Phase 1 — Scaffold both SvelteKit apps

### Task 1: Scaffold student app (`src/frontend`)
**Files:**
- Create: `src/frontend/package.json`, `svelte.config.js`, `vite.config.ts`, `tsconfig.json`, `.npmrc`, `.env`, `src/app.html`, `src/app.css`, `src/routes/+layout.svelte`, `src/routes/+layout.ts`, `src/routes/+page.svelte` (placeholder), `src/lib/api/client.ts`, `src/lib/query/index.ts`, `src/lib/stores/auth.ts`, `src/lib/stores/locale.ts`, `src/lib/stores/sse.ts`, `src/lib/i18n/index.ts`, `src/lib/i18n/messages/en.json`, `src/lib/i18n/messages/ar.json`, `src/lib/icons/index.ts`, `src/lib/types/api.ts`, `static/favicon.svg`

**Interfaces:**
- `client.ts` exports `apiFetch(path, opts)` → `Promise<Response>` injecting `Authorization: Bearer <authToken cookie>` and normalizing FastAPI `detail` errors into thrown `ApiError{detail, status, dependents?}`.
- `query/index.ts` exports `createQuery(key, fetcher, {staleTime})`, `mutate(fn, {invalidates})`, `invalidate(keyPrefix)`.
- `auth.ts` exports `authStore` (`{token, user, isAdmin, loading}`) with `login/register/logout/loadUser`.
- `locale.ts` exports `localeStore` (`{locale, dir}`) with `setLocale`.
- `sse.ts` exports `sseStore` + `connectSSE(token)` bridging `EventSource('/realtime/events')`.
